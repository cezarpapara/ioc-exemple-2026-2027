## Ce conține

Zece mini-aplicații (opt web și două Python), fiecare realizată în patru variante de calitate a interfeței:

| Nivel | Denumire | Pe scurt |
|---|---|---|
| 1 | Nu merge (*doesn't work*) | sarcina se realizează greu sau deloc |
| 2 | Merge (*works*) | își face treaba, dar este neintuitivă |
| 3 | Merge bine (*works well*) | clară, consecventă, cu feedback, responsivă |
| 4 | Merge foarte bine (*works very well*) | în plus: accesibilitate, prevenirea erorilor, detalii de finețe |

Pe fiecare pagină, butonul „Ce nivel are această interfață?” dezvăluie nivelul. Încercați întâi să-l ghiciți și să-l argumentați.

| Folder | Aplicația | Laborator |
|---|---|---|
| `01-automat-cafea` | Automat de cafea | L05 Prototiparea interfețelor |
| `02-automat-bilete` | Automat de bilete de autobuz | L03 Legea lui Fitts și KLM |

Fiecare folder are o fișă de lucru, cu sarcinile și exercițiile laboratorului, în două formate: `FISA.pdf` (pentru citit și tipărit) și `FISA.md` (text). Prezentarea generală a aplicațiilor se află în rădăcină, în `Prezentare-aplicatii-exemplu.pdf`.

## Cum se folosește

1. Pe pagina proiectului de pe GitHub apăsați **Code → Download ZIP** și dezarhivați folderul (nu aveți nevoie de Git).
2. Deschideți `index.html` în browser (dublu-click) sau, în VS Code, cu extensia **Live Server**.
3. Aplicațiile Python (folderele 09 și 10) se rulează cu Python 3 (de pe [python.org](https://www.python.org/downloads/)); Tkinter este inclus: `py 3-merge-bine.py` pe Windows, `python3 3-merge-bine.py` pe macOS.
